# המנוע שמתחת לרגלינו — תהליכים פנימיים בכדור הארץ

לומדה אינטראקטיבית למורים (הכוורת · גיאוגרפיה · יחידה 1). היחידה פותחה ע"י נדב שמגר, מורה ומרצה לגיאוגרפיה, טכנופדגוג. נבנה על ידי נדב שמגר בעזרת בינה מלאכותית.

## מבנה

- הזמנה ללמידה → חלק א׳ (מבנה כדור הארץ, טקטוניקת הלוחות, תופעות משנה) → חלק ב׳ (מהתוכן לכיתה, פורום) → חלק ג׳ (מהלך חקר לכיתה) → העשרה → בוחן סיכום → סיכום ולוח שיתופי → אישור ביצוע.
- ארבע הדמיות דינמיות: פתיחה והתרחקות, הפחתה והתקרבות (שלושה מצבים), החלקה, צונאמי.
- 11 שאלות תרגול (שני ניסיונות, ניקוד מלא גם בשני) — 30% מהציון; 8 שאלות בוחן (ניסיון אחד, ללא חזרה) — 70%.
- אישור ביצוע עם שם, ציון, משוב אישי, השיתוף בפורום ובלוח — הדפסה/PDF והורדת סיכום.
- מצב מורה: הקלדת 74646 בשדה השם — ניווט חופשי ללא שמירה.
- ההתקדמות נשמרת בדפדפן (localStorage).

## נאמנות לתוכן

כל טקסטי הלמידה, השאלות והמשובים הועתקו מהמסמך "כוורת - גיאולוגיה" ללא שינוי. הסברי המשוב לשאלות הבוחן (שאין להם משוב במקור) נוספו. היכן שבמסמך הופיעו שתי גרסאות לפסקה (המעטפת; פתיח הפורום) נבחרה הגרסה המעודכנת לפי הערות המסמך.

## הפעלה מקומית

```
python -m http.server 4190
```

ופתיחת http://localhost:4190 (אין לפתוח את index.html ישירות כקובץ — מודולי JS דורשים שרת).
